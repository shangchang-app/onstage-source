# V1.8 动物探索 → 短实践 → 完整实践

> 基线 `main` @ `1f44fe6`。保留黑白视觉。不发布正式站。
> 本轮不做：社区、企业自助后台、AI 人才评分、付费系统。

## 1. 新增两个 5–8 分钟短实践

两个都建在现有「短版」4 步框架上（收到任务 → 看材料 → 选择 → 复盘），新增「选一项」模式：选一项 → 写一句理由 → 点「看这个选择的反馈」马上看到为什么、有什么取舍 → 再写一句后续 → 复盘。

| | AI 方向 `ai-answer-check` | 出海方向 `growth-feedback` |
|---|---|---|
| 标题 | 这条 AI 回答哪里不可靠？核对规则，写一句修改建议 | 6 条用户反馈，先验证哪个问题？写出验证办法 |
| 时间 | 约 6 分钟 | 约 7 分钟 |
| 情境 | 用户投诉 AI 客服「答应能退，结果被拒」 | 口语 App 上线东南亚三周，注册的人很少 |
| 材料 | 被投诉的对话、退换货规则、订单信息、回答规范 | 6 条用户反馈、注册漏斗、团队记录 |
| 选一项 | 4 句回答里最需要先改的一句 | 4 个问题里最该先验证的一个 |
| 一句后续 | 修改建议 | 验证办法（找谁、做什么、看什么、怎样算成立） |
| 成果 | AI 回答检查单 | 问题验证卡 |
| 做完推荐 | 完整实践 `ai-eval`（约 40 分钟） | 完整实践 `overseas-growth`（约 40 分钟） |

- 每个选项都有平台事先写好的反馈：「为什么」和「要权衡的」。只有一个选项标「依据最充分」，其余标「有道理，但不是最先要做的」或「材料里的依据不够」。
- 反馈只看选了哪一项，不读用户写的理由；界面写明「不是 AI 点评，也不是分数」。可以改选再看，复盘里会记下第一次看的是哪一项。
- 复盘：用户自己写的内容原样展示、所选项的反馈、其他选项为什么、没打开的关键材料、参考复盘（不是标准答案）、自查清单。不打分，不评价适不适合这个方向。
- 店铺、App、规则、反馈和数据全部是教学模拟内容，页面和「内容来源」里都标明；AI 回答是平台人工编写的样例。数字互相一致（漏斗核算写在 `scripts/exp-growth-check.ts` 开头）。
- 零基础可做，有提示、参考句式和术语解释。

## 2. 动物结果推荐

- 结果页的推荐改成两级：**第一步 · 先花几分钟试试**（短实践）和 **第二步 · 想学得更完整**（完整实践）。每张卡都写预计时间和「能学到」。
- 卡片下方写明：「推荐只是按这次的选择挑了一个话题，不代表你适合或不适合哪个方向。」推荐语里不出现「适合 / 擅长 / 能力」等说法（有测试检查）。
- 13 个结果的对应关系：

| 短实践 → 完整实践 | 结果 |
|---|---|
| AI 回答核对 → 4 个 AI 回答做评测标准 | 水獭、猫、猫头鹰、刺猬 |
| 用户反馈选问题 → 一款产品进入新市场先验证什么 | 狐狸、松鼠、海豹、企鹅、兔子、鸭嘴兽 |
| 订单涨了利润少了（原短版）→ 退货率完整版 | 边牧、浣熊、章鱼 |

- 只改推荐，不改题目、计分和判定规则，所以题目版本仍是 v2；已保存的动物结果打开后直接显示新的推荐。

## 3. 成果与继续学习

- 短实践沿用现有的草稿保存（自动保存、刷新恢复、冲突处理）、成果保存、备份导出导入和校验机制。
- 复盘页顺序：你的判断 → 反馈 → 参考复盘 → 保存成果 → 轻量反馈 → 「想学得更完整？」（完整版的时间、会进一步学什么）。
- 「我的 → 继续体验」：短实践保存成果后，这一行多一句「下一步：完整实践「……」（约 40 分钟）」。
- 详情页的流程、步骤名按这个短实践自己的写法显示，并说明做完可以接哪个完整版。

## 4. 轻量反馈

- 短版复盘页（包括原来的「订单涨了利润少了」）都有「这次短实践怎么样？」：有帮助 / 没看懂 / 太简单 / 太难，原因选填（最多 500 字）。
- 现在没有接服务器：反馈只存在这台设备的浏览器里（`onstage-feedback:v1`），页面写明「不会自动发送给平台」；保存后的提示是「已保存在这台设备上……没有发送给平台」，不说「已提交」。
- 同一个体验的同一版本只留一条，再保存就是修改。
- 「我的 → 我的反馈」可以查看和导出（JSON，文件里也写明未发送）；反馈也进「备份」，导入时同一条保留较新的。旧版备份没有反馈字段，照常导入。

## 5. 兼容

- 内容结构只加了可选字段（`mode`、`stepNames`、`flow`、文案字段、`deepWhy`），不写就是原来的行为；原短版的完成规则、复盘和步骤名不变。
- 短实践里不合法的旧选择（多选、选项已不存在）提示重新确认，不替用户选，也不改动草稿。
- 版本号改为 1.8.0。
