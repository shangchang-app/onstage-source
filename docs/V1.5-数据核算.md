# V1.5 旗舰短体验：模拟数据核算

所有数字都是**模拟教学数据**，不对应任何真实店铺。这里列出计算方法，`tests/quick.test.ts` 会自动重算并核对。

## 计算口径（模拟参数）

- 单件毛利 = 售价 − 平台佣金 12% − 配送费 $6.50 − 货品成本 $15.69
  - $39.99：39.99 − 4.80 − 6.50 − 15.69 = **$13.00**
  - $35.99：35.99 − 4.32 − 6.50 − 15.69 = **$9.48**
- 每笔退货损失 = 这一单的毛利 + 退货运费和处理费 $8（假设退回商品可以重新入库）
- 估算净利润 = 订单毛利合计 − 退货损失 − 广告花费
