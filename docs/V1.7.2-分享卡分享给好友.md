# V1.7.2 修复：试玩版分享卡不能分享给好友

> 基线 `main` @ `8ed4781`。只改「隐藏工位搭子」分享卡的分享方式，不改卡片画面、推荐规则和其他功能。不发布正式站。

## 问题

试玩版结果页只有「保存分享卡」：弹窗里只能「下载图片」。要发给好友得先存到相册，再去聊天 App 里找图片。微信里连下载按钮都不显示，只提示长按保存。

## 修改

试玩版是纯静态网页，没有服务器，接不了微信 JS-SDK（需要服务器签名），所以按浏览器能力分三种情况：

| 环境 | 能做什么 |
|---|---|
| 支持系统分享的手机浏览器（iPhone Safari、安卓 Chrome 等） | 「分享给好友」打开系统分享面板，**带上分享卡图片**和「一句话 + 探索链接」，可以直接选微信、QQ 等发给好友。不支持带图片的浏览器改为分享探索链接，并提示可以先下载图片再发 |
| 所有浏览器 | 「复制链接」：复制「我在 on stage 的隐藏工位搭子是「…」：…  你的是谁？ + 探索链接」，粘贴到聊天里。剪贴板不能用时显示文字让用户手动复制 |
| 微信、QQ、微博等 App 内置浏览器 | 网页调不起系统分享，提示：**长按图片**选「发送给朋友」或「保存图片」；也可以点右上角「···」→「发送给朋友」把探索页发出去。图片改为 data: 图片，长按才有发送 / 保存菜单。也可以复制链接 |

- 结果页按钮从「保存分享卡」改为「分享给好友」，弹窗标题同步；分享、复制、下载按钮放在图片正下方（手机上不用滚到底才看到）。
- 分享出去的只有角色、一句话和探索链接（`/buddy/`，不带参数），不带作答。
- 不显示假的「分享成功」：系统分享面板关掉后只说「已把分享卡交给你选的 App」；用户取消不提示；打不开时明确说没有打开，并给出复制链接、下载图片的办法。

## 回归测试

- 新增 `tests/e2e/share-check.cjs`（7 项，已加入 `npm run test:pages`，另有 `npm run test:share`）。系统分享面板和剪贴板用替身模拟，检查页面交给系统的内容：
  1. 能分享图片：带 PNG 分享卡、一句话、探索链接，不带作答；手机打开弹窗就能看到「分享给好友」；提示不说「成功」。
  2. 只能分享链接：改为分享不带参数的探索链接。
  3. 用户取消：不报错、不说已分享。
  4. 打不开：说明没有打开，给出复制链接和下载图片。
  5. 电脑浏览器没有系统分享：不显示「分享给好友」；复制链接的内容正确；下载图片可用。
  6. 剪贴板不能用：显示文字让用户手动复制。
  7. 微信内置浏览器（模拟 UA）：不显示下载和系统分享按钮；提示长按发送或右上角「···」；图片是 data: 图片；可复制链接。
- 在修复前的构建上 7 项都失败（没有「分享给好友」）。
- `tests/e2e/buddy-check.cjs`：结果页按钮名改为「分享给好友」；微信提示的期望改为长按发送 / 保存。

## 没验证的

- 真机上的系统分享面板（iPhone Safari、安卓 Chrome）实际能不能带图片发到微信，各手机系统和微信版本表现可能不同。
- 微信内置浏览器里长按 data: 图片是否出现「发送给朋友」，右上角「···」分享出去的标题和图标（没有 JS-SDK，由微信默认决定）。
- 国内网络访问。
